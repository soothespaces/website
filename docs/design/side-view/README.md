# Side view design boards

Screenshots of the side view design canvas, one PNG per board, rendered at 2x. Agents
working the [Side view build](https://linear.app/soothespaces/project/side-view-build-798642e2759a)
tickets can't open the canvas, so each ticket names the board it builds and these files
are the reference. Match the copy written in the ticket; the image shows layout and
styling.
